# Circles 3.1 — 05 UX

- **Create or organise** (Quick actions, first item; centred dialog, no drawer): Create something new · Bring something
  into this Circle · Quick actions. Only possible actions are buttons; partner listing types are explained in one line
  when the person has no partner account or isn't an organiser.
- **Link existing**: one search across activities, adventures, experiences, volunteering, programmes and places (the
  public search, so only discoverable listings), type chips, result rows with image, type, date, place, price; then a
  clear choice — *Link it to the Circle* (nobody signs up) or *Plan to go together* (a plan).
- **Linked to this Circle** (Activities tab): waiting-for-organiser group, type filter, each row with the live listing
  block and its own CTA (Book adventure, Enrol in programme…), *Plan together*, Approve/Decline, Remove (confirmed).
  Empty: "No plans yet — Your Circle's next good day starts with an idea." with Suggest / Explore / Link.
- **Creating for {Circle}** banner on the activity form and the partner create pages, saying who owns it, whether an
  organiser or HelloCircle approves it, and what happens next; a failed attach offers *Try again*.
- **Listing pages**: the existing "Plan with my Circle" dialog now asks *Plan to go together* or *Share it with the Circle*.
- Phone: checked at 375 (no overflow). Booking CTAs stay the main action on listing pages.
