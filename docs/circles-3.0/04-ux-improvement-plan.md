# Circles 3.0 — 04 UX improvement plan

## Done in this pass

- **Plan cards say what the plan is about**: kind label (Activity, Adventure, Experience, Volunteering, Programme,
  Place), live facts (date, place, price), availability chip (Full / Cancelled by the provider / No longer
  available), your state (You've booked / You're on the waitlist / You're interested (not booked)), and one link
  named for the action ("Book experience →", "Enrol in programme →"). "Being in this plan doesn't book you a place."
- **Plans filter by kind**, only for kinds present.
- **Listing pages**: a labelled "Circle" icon next to Share / Invite / Directions — secondary to the main Book /
  Join button. Dialog: which Circle, optional date (departures / sessions), optional message; success links to the
  plan; a duplicate says "Already suggested" and links to it.
- **Share sheet**: "Also add it to the Circle's plans" (off by default); share errors are now shown.

## Built since

My Life "Plans you're in", "Explore with others", cancellation notices, day-before reminders, admin Close/Reopen.

## Phase 4 proposals — need owner decisions before building (not built on purpose)

- **Host/vendor promotion to Circles** — letting providers push listings into Circles they don't belong to is a
  marketing channel into private groups; needs rules on consent, frequency and whether it's paid (commercial
  decision, no fees may be added without approval).
- **One plan across several Circles for a listing** — extends Circle-to-Circle (activities today) to listings;
  needs the D2-style approval flow per Circle.
- **Recurring plans** ("every Saturday parkrun") — overlaps Routines and repeating activities; decide which owns it.
