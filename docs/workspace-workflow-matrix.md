## Cross-cutting integrity checks (code-reviewed)
- **Double booking:**
  - Hall bookings are row-locked in a transaction (`bookings.ts`).
  - Game seats are row-locked (`gameSeatSql`).
  - Capacity counts held payment reviews (`occupiesCapacitySql`).
  - Availability excludes cancelled rows.
- **Sale gates:** every sale path calls `offeringSellable()` + `assertSellable(tx, vendorId)` (D-01).
- **No client totals:** pricing is computed on the server (`pricing.ts` / engine), and quotes come from the server.
- **Do not change** Checkout metadata `type` literals or bypass `checkoutService`.
